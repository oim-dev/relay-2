# Relay

Relay — рабочая память проекта для людей и AI-агентов.
Монорепозиторий на **Bun + Turborepo + TypeScript**.

## Текущее состояние

Текущий этап — перенос основного функционала в CLI; Server, Web и MCP отложены
до появления рабочей CLI с перенесённым основным функционалом.

Локальная CLI на Gunshi работает с отдельной SQLite-базой каждого проекта.
Предметные команды охватывают знания, документы, задачи, планы, релизы и историю
работы. Workspace объединяет регистрации проектов и обслуживается самой CLI.
Git-синхронизация и `rest-sdk` отложены.

## Быстрый старт

Нужен Bun **1.4.3**, закреплённый в `.bun-version` и `packageManager`.
Установка нужной версии: [инструкция Bun](https://bun.com/docs/installation).

```bash
bun --version
bun install --frozen-lockfile
bun run build:cli
apps/cli/dist/relay --help
apps/cli/dist/relay --version
```

Без аргументов CLI показывает справку. Эти вызовы работают без настроенного проекта.
Создание проекта, workspace и предметные команды описаны в [руководстве CLI](docs/CLI.md).

## Структура

```text
apps/cli/          → приложение relay и его тесты
apps/git-sync/     → заготовка relay-git-sync
packages/          → общие библиотеки и их тесты
docs/              → архитектура и разработка
tests/e2e/         → сквозные сценарии продукта
benchmarks/        → будущие ручные измерения производительности
```

## Основные команды

- `bun run dev:cli` — пересборка CLI при изменениях; выполнение запускается отдельно.
- `bun run build` — типизация и сборка приложений.
- `bun run start:cli` — запуск ранее собранного CLI.
- `bun run lint` / `bun run typecheck` — статические проверки.
- `bun run format:check` / `bun run format` — проверка и применение форматирования.
- `bun run test` — модульные тесты.
- `bun run check` — форматирование, lint, типы, сборка и все функциональные наборы.

Нагрузочные измерения выполняются только вручную по запросу, вне CI и штатных проверок.
