# Измерения производительности

Место для будущего воспроизводимого стенда. Исполняемых сценариев и команды запуска
пока нет. Их разрабатываем отдельно, по необходимости под конкретный вопрос и
по явному запросу.

Профили, метрики, оценка пределов одной проектной БД и нескольких проектов,
а также требования к воспроизводимости описаны в
[руководстве по производительности CLI](../docs/development/CLI-PERFORMANCE.md).

## Запуск

Измерения производительности и нагрузочные сценарии выполняются **только вручную
по явному запросу**. Они не входят в CI, `check`, `test:all`, обычные тестовые scripts
и их зависимости в Turbo.

Сценарии CLI будут размещаться в `benchmarks/cli/` с именами `*.bench.ts`, отдельно
от обнаруживаемых Bun test файлов. Для управления нагрузкой будет использоваться отдельный
Bun-сценарий с `Bun.spawn()`, запускающий настоящий бинарник с заданным числом клиентов.
Команда ручного запуска определяется при появлении стенда.

## Материалы

Базы, origin и процессы стенда изолируются от пользовательских данных. Ресурсы
освобождаются при завершении и отмене. Результаты, логи и подготовленные данные
сохраняются в `.artifacts/YYYY-MM-DD/<название-измерения>` и не коммитятся.

Численные бюджеты определяются для конкретного исследования на зафиксированном
окружении. Небольшая проверка корректности двух конкурирующих записей относится
к обычным [функциональным тестам](../tests/README.md), а не к нагрузочному стенду.
