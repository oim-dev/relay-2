# Измерения производительности

Место для будущего воспроизводимого стенда. Наборы измерений добавляются вместе
с рабочими сценариями и запускаются отдельно от обычных тестов.

Планируем измерять:

- запуск собранного CLI;
- чтение, запись и атомарные пакеты на разных объёмах данных;
- параллельные CLI/Server/Sync, ожидание записи и рост WAL;
- обмен 10+ независимых экземпляров через общий origin;
- восстановление из локального Git и origin;
- задержки p50/p95/p99, потребление памяти и отзывчивость Server.

Сохраняем параметры данных, настройки надёжности БД, платформу и версии инструментов.
Численные бюджеты определяем после первых измерений.
