# @relay/project-runtime

Project Runtime определяет, с каким локальным проектом работает вызов Relay и где
лежат его данные. Он нужен CLI и другому локальному вызывающему коду, чтобы одинаково
находить конфигурацию, создавать проекты и выбирать их из workspace.

Для Bun-кода внутри монорепозитория пакет доступен как `@relay/project-runtime`
после [подготовки репозитория](../../README.md#быстрый-старт). Это приватная библиотека
с исходным TypeScript; пользовательские команды описаны в
[руководстве CLI](../../docs/CLI.md#проект-и-размещение-данных).

Если рабочий каталог — корень инициализированного проекта, получить путь
к его базе можно так:

```ts
import { resolveProject } from "@relay/project-runtime";

const project = resolveProject({ cwd: process.cwd() });
console.log(project.projectId, project.databasePath);
```

Runtime найдёт конфигурацию, проверит базу и совпадение постоянного ID. Он закрывает
проверочное соединение; для дальнейшей работы вызывающий открывает своё через
[Storage](../storage/README.md). Отсутствующая база считается ошибкой, а не поводом
создать пустой проект.

## Как задаётся контекст

Без `config` проверяются только `relay.config.json` и `relay.workspace.json` в `cwd`.
Явный `config` выбирает файл напрямую;
явные относительные пути внутри файла разрешаются от его физического каталога, включая
символьные ссылки. Для workspace передайте `project` — имя регистрации. Workspace
хранит регистрации `{ name, path }` с путями каталогов независимых проектов;
каждый каталог должен содержать собственный `relay.config.json`. Удаление регистрации
сохраняет данные проекта. `listProjects` возвращает абсолютные пути каталогов.

`initializeProject` создаёт базу в `<home>/projects/<id>/project.sqlite` и затем
публикует конфиг с `version` и `projectId`. `resolveProject` использует то же размещение,
если в конфиге не задан явный `databasePath`. `home` по умолчанию — `~/.relay`;
нестандартный корень передаётся и при создании, и при выборе или регистрации проекта.
Значение `RELAY_HOME` передаёт вызывающая CLI через параметр `home`:
библиотека сама не читает эту переменную окружения. Правила переопределения и смены
расположения описаны в [руководстве CLI](../../docs/CLI.md#проект-и-размещение-данных).
