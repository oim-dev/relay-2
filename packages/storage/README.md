# @relay/storage

Storage сохраняет локальные данные Relay и защищает их от частично выполненных
операций и перезаписи устаревшей версии. Каждый проект имеет собственную SQLite-базу.
Пакет нужен Core для выполнения сценариев и приложению — для открытия и закрытия
соединения с выбранным проектом.

Пакет приватный, использует `bun:sqlite` и экспортирует исходный TypeScript.
Окружение готовится по [корневому быстрому старту](../../README.md#быстрый-старт).
Для предметных изменений приложение вызывает Core; Storage предоставляет механизм
хранения и возвращает сырые записи, содержимое которых проверяет Core.

## Прочитать страницу задач

Этот фрагмент предназначен для Bun-кода приложения внутри монорепозитория.
Рабочий каталог должен быть корнем инициализированного проекта с `relay.config.json`
([создание проекта](../../docs/CLI.md#проект-и-размещение-данных)).

```ts
import { resolveProject } from "@relay/project-runtime";
import { ProjectDatabase } from "@relay/storage";

const location = resolveProject({ cwd: process.cwd() });
const database = ProjectDatabase.open(location.databasePath);
try {
  const page = database.listPage("task", { offset: 0, limit: 20, sort: "key" });
  console.log(
    page.items.map((task) => task.key),
    page.total,
  );
} finally {
  database.close();
}
```

Результат — до двадцати ключей задач и их полное число из одного снимка. `listPage`
загружает только выбранное окно; `list` загружает весь набор с содержанием.

`ProjectDatabase.open` требует существующую совместимую базу и не создаёт пустую
вместо утраченной. Соединение принадлежит вызывающему и закрывается в `finally`.
Связанные записи объединяются через `transaction`, составные чтения — через `snapshot`;
оба callback строго синхронны. WAL допускает чтение при активном писателе, но запись
в один файл выполняется последовательно.
