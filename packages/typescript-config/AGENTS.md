# Работа над профилями TypeScript

- Выбирай область изменения по [назначению профилей](README.md#выбор-профиля):
  общие правила проверки — в `base.json`, типы Bun — в `bun.json`, браузерные
  библиотеки — в `browser.json`. Пути исходников и частные настройки остаются
  у потребителей.
- Сохраняй явное подключение типов окружения: `base.json` не должен автоматически
  подхватывать все установленные `@types/*`. Изменение `types` в дочернем профиле
  заменяет массив, а не дополняет его.
- Профили служат проверке типов без генерации файлов. Не включай общий emit ради
  сборки одного приложения. При изменении имён или состава профилей согласуй
  `exports` в `package.json` и реальные `extends` потребителей.
- Проверяй изменения через потребителей: для `bun.json` — Bun-компоненты и
  `tests/tsconfig.json`, для `browser.json` — `@relay/rest-sdk`, для `base.json` —
  всех, поскольку остальные профили наследуют базовый. Команда `bun run typecheck`
  из корня репозитория охватывает эти конфигурации; собственной проверки у пакета нет.
