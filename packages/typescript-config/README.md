# Профили TypeScript

`@relay/typescript-config` задаёт общие строгие настройки проверки TypeScript для
компонентов Relay. Разработчик выбирает профиль под среду выполнения своего пакета,
а пути исходников и особенности сборки задаёт в самом компоненте.

## Выбор профиля

- **`base.json`** — для переносимых библиотек без глобальных типов конкретной среды.
  Его использует `@relay/contracts`.
- **`bun.json`** — для приложений и библиотек, работающих в Bun. Подключает типы Bun;
  потребителю нужен `@types/bun` в `devDependencies`.
- **`browser.json`** — для кода с браузерными API: добавляет типы DOM и DOM.Iterable.
  Сейчас используется заготовкой `@relay/rest-sdk`.

Базовый и браузерный профили не подключают глобальные типы из установленных
`@types/*` автоматически. Нужные дополнительные типы окружения указывайте в
`compilerOptions.types` своего компонента. Этот массив заменяет унаследованный:
при расширении профиля Bun сохраняйте в нём `"bun"`.

## Подключение

Пакет используется внутри монорепозитория после
[установки зависимостей](../../README.md#быстрый-старт). В `devDependencies`
компонента указывается `"@relay/typescript-config": "workspace:*"` и TypeScript;
для профиля Bun также нужен `@types/bun`.

Например, [конфигурация Git Sync](../../apps/git-sync/tsconfig.json) подключает
профиль Bun и выбирает свои исходники и тесты:

```json
{
  "extends": "@relay/typescript-config/bun.json",
  "include": ["src/**/*.ts", "tests/**/*.ts"]
}
```

Проверить типы этого компонента можно из корня репозитория:

```bash
bun run --filter @relay/git-sync typecheck
```

Профили настроены на проверку без генерации JavaScript. Самостоятельной сборки у
пакета настроек нет; сборку приложения определяет его собственный скрипт.
