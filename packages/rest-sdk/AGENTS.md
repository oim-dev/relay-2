# Работа над REST SDK

- Перед изменениями прочитай [README](README.md) и
  [границы HTTP-взаимодействия](../../docs/ARCHITECTURE.md#расширение-после-cli).
  Реализация клиента и генерация из API требуют отдельной задачи; наличие пакета
  не расширяет текущий этап локальной CLI.
- Сохраняй совместимость с браузерной средой: пакет использует `browser.json`.
  Не добавляй зависимости от Bun, SQLite, Core или локального контекста проекта.
  Общие переносимые контракты принадлежат `@relay/contracts`.
- При изменениях заготовки выполняй `bun run --filter @relay/rest-sdk typecheck`
  из корня репозитория. Собственных HTTP-сценариев и тестов пока нет; скрипты `test:*`
  допускают отсутствие тестов и не подтверждают готовность клиента.
