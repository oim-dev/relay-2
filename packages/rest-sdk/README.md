# REST SDK

`@relay/rest-sdk` — заготовка общего HTTP-клиента Relay для будущего Web-интерфейса
и удалённого режима CLI. Пакет предназначен разработчикам этих интерфейсов, чтобы
работать с серверным API через общий клиент.

Сейчас пакет не экспортирует публичных функций и не выполняет HTTP-запросов:
сервер и его API ещё не реализованы, поэтому клиент пока недоступен для использования.
Локальная CLI обращается непосредственно к Core и не использует этот SDK.

Назначение пакета и границы будущего HTTP-взаимодействия описаны в
[архитектуре Relay](../../docs/ARCHITECTURE.md#расширение-после-cli).
Для доступных пользовательских сценариев см. [руководство CLI](../../docs/CLI.md).
