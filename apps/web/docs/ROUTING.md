# Маршруты Web

`P` ниже означает `/projects/:project`, где канонический адрес проекта — постоянный ID.
Отображаемое имя и slug не меняют идентичность кеша, форм и запросов.
Имена регистраций workspace и известные Server при запуске slug принимаются как
совместимые алиасы и перенаправляются на ID. Неоднозначный alias не открывает
случайный проект. Для сохраняемых ссылок используйте канонический адрес с ID:
реестр адресов фиксируется при запуске Server, независимо от последующих правок slug.

| Адрес                                                                          | Экран                         |
| ------------------------------------------------------------------------------ | ----------------------------- |
| `P`                                                                            | Обзор                         |
| `P/settings`                                                                   | Настройки проекта             |
| `P/product/passport`, `/edit`                                                  | Паспорт и редактор            |
| `P/product/features`, `/new`                                                   | Каталог и создание фичи       |
| `P/product/features/:feature`, `/edit`                                         | Фича и редактор               |
| `P/product/features/:feature/scenarios/:scenario`, `/edit`                     | Сценарий и редактор           |
| `P/product/features/:feature/scenarios/new`                                    | Создание сценария             |
| `P/product/applications`, `/new`                                               | Каталог и создание приложения |
| `P/product/applications/:application`, `/edit`, `/scope`                       | Приложение, редактор, состав  |
| `P/product/applications/:application/implementations/:implementation`, `/edit` | Реализация                    |
| `P/documents`, `/new`, `/:document`, `/:document/edit`                         | Библиотека и документ         |
| `P/boards/:boardSlug`                                                          | Канбан                        |
| `P/boards/:boardSlug/:taskId`                                                  | Окно задачи над доской        |
| `P/plans`, `/:planId`                                                          | Каталог и план                |
| `P/releases`, `/:releaseId`                                                    | Каталог и релиз               |
| `P/work-history`                                                               | Граф истории                  |
| `P/relations`, `/context`                                                      | Связи и визуальный контекст   |

Существующие адреса Relay 2 `/knowledge/:kind`, `/entities/:ref`, `/board`, `/tasks/:id`,
`/history` и `/history/sessions/:ref` открываются через совместимые переходы.
Адресная карточка разрешается по текущим данным Core, включая принадлежность сценария
фиче и реализации приложению. Неизвестная сущность не выбирает другую запись.

Доска сохраняет `q`, `blocked` и `cancelled`; библиотека — поиск, вид, раздел, тип,
порядок и продолжение. Смена фильтра начинает новый список. Продолжение передаёт
generation исходной страницы; изменение поколения требует перечитывания.

Открытие задачи с доски сохраняет фон и фильтры. Закрытие использует историю перехода,
а прямая ссылка возвращает к фактической доске. История использует query выбора точки
или материала; закрытие возвращает к тому же холсту. Back/Forward и reload должны
работать независимо от способа входа.

Фактическое дерево находится в `src/app/router/app-router.tsx`. Его ветки согласованы
с HTML fallback Server; неизвестные API, assets и Worker-запросы не получают HTML.
