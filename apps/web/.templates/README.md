# Генерация компонентов Relay

Запускать из корня репозитория:
`bun run --filter @relay/web create <шаблон> <имя> <каталог владельца>`.
Каталог владельца указывается относительно `apps/web`.

- `ui-component`: внутренняя реализация владельца без фасета.
- `ui-unit`: самостоятельная визуальная ответственность с `index.ts`.

Шаблоны основаны на React Reference. Перед запуском прочитать все файлы выбранного
шаблона. Результат адаптировать в том же изменении: назначение, свойства, корневой
элемент, стили и минимальный публичный API. Компоненты без DOM сохраняют свою папку,
но не искусственные DOM-атрибуты и CSS. Генератор не перезаписывает существующие файлы.
