# Relay Web

Браузерный интерфейс Relay на основе исходных экранов первой версии: обзор проекта,
продуктовые знания, библиотека документов, канбан с модальной карточкой задачи,
планирование, релизы, история и визуальный контекст.

Данные и операции принадлежат текущему Relay 2. Web обращается к Server через
`@relay/rest-sdk`; CLI и браузер используют одну проектную SQLite-базу и правила Core.
Сборка этого приложения входит в поставку `relay-server`.

После [сборки Relay](../../README.md#быстрый-старт) запустите из проекта или workspace:

```sh
relay server run
```

Для разработки с отдельным Vite используйте из корня репозитория:

```sh
RELAY_API_URL=http://127.0.0.1:3210 bun run dev:web
```

Server должен разрешать origin `http://127.0.0.1:5174`. Vite выполняется под Node.js,
зависимостями управляет Bun.
