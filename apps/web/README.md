# Relay Web

Relay Web — браузерный интерфейс к рабочей памяти проекта: описанию продукта, знаниям,
документам, задачам, планам, релизам и истории. Он помогает перейти от требования к
работе и сохранить контекст для её продолжения.

Откройте URL Relay Server с подключённой Web-сборкой. В локальном режиме открывается
один проект, в workspace сначала выберите нужный. Недоступные регистрации остаются
видимыми вместе с причиной отказа. Начните с паспорта продукта, добавьте фичу,
связанный документ и задачу на доске — данные доступны также через локальную CLI.

Web использует общий REST SDK, а предметные изменения проверяет Core. Черновики
сохраняются в памяти вкладки при переходах и конфликтах. Отдельный индикатор Git Sync
показывает состояние обмена: локальное сохранение и подключённые события сервера
не означают доставку изменений в общую ветку.

## Дальнейшие шаги

- [Использование](docs/USAGE.md) — сценарии, черновики, конфликты и адреса страниц.
- [Server](../server/README.md) — подключение к локальному проекту или workspace.
- [Архитектура Web](docs/ARCHITECTURE.md) — владельцы интерфейса и состояния.
- [Разработка](docs/DEVELOPMENT.md) — запуск, навыки, генерация TSX и browser-приёмка.

Технологическая основа — React, Mantine, SWR и React Router. Vite запускается под
**Node.js**; Bun управляет workspace и зависимостями. Готовые статические ресурсы
передаются Server, поэтому отдельный Vite нужен только для разработки.
