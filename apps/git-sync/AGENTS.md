# Работа над Git Sync

- Перед изменениями прочитай [README](README.md) и
  [границы Git-обмена](../../docs/ARCHITECTURE.md#синхронизация-и-последующие-интерфейсы).
  Заготовка не является разрешением начинать синхронизацию: её реализация требует
  отдельной задачи.
- Git-транспорт относится к этому приложению; предметное применение полученных
  изменений должно проходить через Core. Локальные пути и выбор проекта принадлежат
  Project Runtime. Не переноси эти ответственности в заготовку ради будущего обмена.
- При изменениях каркаса проверяй типы командой
  `bun run --filter @relay/git-sync typecheck` из корня репозитория. Если затронуты
  точка входа или сборка, там же выполни `bun run build:git-sync` и
  `bun run start:git-sync`; ожидается сообщение о недоступности синхронизации.
- Скрипты `test:*` допускают отсутствие тестов. Их успешное завершение не подтверждает
  работу Git-обмена.
