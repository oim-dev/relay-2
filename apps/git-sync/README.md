# Relay Git Sync

`@relay/git-sync` — заготовка отдельного приложения для обмена данными Relay через Git.
Компонент предназначен для будущей синхронизации независимых локальных копий проекта
между участниками команды.

Сейчас бинарник `relay-git-sync` только сообщает, что синхронизация не реализована.
Пользовательских команд обмена данными нет. Для локальной работы с проектами используйте
[CLI Relay](../../docs/CLI.md).

## Запуск заготовки

Разработчик может проверить сборку и запуск после
[установки зависимостей монорепозитория](../../README.md#быстрый-старт).
Из корня репозитория:

```bash
bun run build:git-sync
bun run start:git-sync
```

Результат запуска — сообщение «Relay Git Sync: каркас приложения. Синхронизация пока не реализована.»

[Архитектура Relay](../../docs/ARCHITECTURE.md) описывает границы компонента и целевую
модель Git-обмена; реализация синхронизации отложена.
